# 项目初始化 Workflow

## 进入条件

新建独立产品，或目标目录只有管理脚手架、尚无服务本次目标的产品运行链路。

## 顺序与门

明确目标与项目上下文/接入 → 技术栈与主链路设计 → 方案 Review → 最小完整项目与首条运行链路 → 真实使用验证 → 实现 Review → 交付 → 复盘。

附加门见[项目初始化方法](../skills/development-lifecycle/references/project-initialization.md)。已有产品新增功能、修复和纯规则接入不进入本流程。

## 调度与返回

由 [Development Lifecycle](../skills/development-lifecycle/SKILL.md) 选择当前阶段 Skill、处理返工并检查完成门；本文件只定义本流程路径，不复制阶段方法。

单项任务按其目标范围交付；嵌套在[大型交付](major-delivery.md)时，返回本工作项的结果、证据、风险与未闭合项，由外层集成并核对整体目标。子流程结束不关闭 parent-goal，仍保留 Lifecycle 的适用复盘与完成要求。
