# Bibo 产品方向

Bibo 探索成为用户拥有、各种获授权的 AI 与系统都能接入的个人全局上下文与资产中心。

用户的笔记、资料、项目、任务、决策和工作成果可以持续积累，并被不同 AI 在合适范围内继续使用。空间中的资产与技术能力是价值重心。内置助手保留，帮助用户管理、整理与使用上下文。

## 已确认的项目关系

- Bibo 是独立产品，在 `Peiiii/bibo` 独立开发、制定路线与发布。
- NextClaw 以长期智能搭档与执行能力为核心；Bibo 继续通过公共包复用适用的底层能力，双方通过明确公共边界协作。
- NextClaw 未来可以成为 Bibo 的重要接入方；该关系不是对已有连接功能的完成声明。
- Bibo 面向其他 Agent 开放的方向保持独立，不要求用户只能使用内置助手。

## 当前能力与探索方向

当前已有对话、笔记/文件、项目、任务、日程、收件箱、云端持久化与按需 Linux 沙箱。开放 API、Skill、CLI，以及更完整的跨 Agent 上下文与协作能力仍需要设计和实现。

“公共个人”的数据公开范围、首批用户、上下文对象模型和协作协议尚未冻结；不能把开放接入等同于公开个人数据。
