# Bibo 开放空间交付计划

状态：全部完成；实际交付与验证见原验收账本和交付记录。

上位：[方案](../designs/2026-10-22-bibo-open-api.design.md)；合同 `bibo-open-api-v1` r1；恢复只读[当前状态](../work/2026-10-22-bibo-open-api/current-state.md)。全部部分复用上位设计；出现新协议/状态分叉先回原设计修订和 Review。

1. API/授权：公共类型与 SDK、原 owner 幂等、DO key、版本化 API。输入原空间动作，输出安全可联调合同。验证鉴权/隔离/错误/版本/重试/Worker；通过后供 CLI/UI 消费。
2. CLI/网页/Skill：对象命令、安全认证、授权管理 UI、标准 Skill。输入 API，输出可用用户链路。验证命令真实请求、安全文件权限、桌面/手机和复制/撤销。
3. 文档/发布：公开文档站、准确能力参考、CI 和包发布脚本。输入已验证合同，输出可安装 tarball 和可部署静态站。验证包内容/隔离安装/文档链接/两种应用构建。
4. 统一验证/Review/交付：完整回归与安全审查，提交推送，CI 发布 NPM，冻结主线部署应用及文档，真实线上验收、清理 smoke 资产，更新账本。未验证部分不能标为交付；中断后先查外部发布结果再继续，禁止重复发布。

单一代理负责各 owner 实现；每部分关键结果写原日志，不建立额外进度副本。
